O que motiva você no trabalho?

Responda 30 perguntas distribuindo 3 pontos entre duas respostas possíveis. No final, você recebe um relatório individual com sua principal motivação no trabalho e o percentual de cada elemento, pronto para salvar em PDF.

Como funciona

1

Informe seu nome completo. E-mail e setor são opcionais.

2

Em cada pergunta, distribua 3 pontos entre as respostas A e B: quanto mais pontos, mais ela combina com você.

3

Veja a porcentagem de cada área, o gráfico e salve o relatório em PDF.

Seus dados

Informe seu nome completo para continuar.

3 pontos

Escolha de 0 a 3 pontos para uma das respostas: a outra recebe automaticamente o que falta para completar 3. Para trocar o lado que você preenche, use “Limpar escolha”.

Percentual = pontos obtidos ÷ (nº de questões do elemento × 3) × 100. Cada pergunta distribui 3 pontos entre dois elementos.

Para salvar em PDF, escolha “Salvar como PDF” como destino na janela de impressão.

Projeto de curricularização desenvolvido como atividade acadêmica. As respostas são guardadas no banco de dados do projeto e usadas apenas para o diagnóstico.
